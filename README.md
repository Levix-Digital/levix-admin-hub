# levix-admin-hub

The Levix Admin Hub: the control plane of the Levix products (AnyContext, DocMapper and
future ones). Always hosted by the customer, zero-knowledge: it governs installations —
users, devices, policies, licenses, updates — and never sees content.

No code yet: it is born here when its backlog items are built, in Rust, sharing the policy
model and signature verification with `levix-platform`.

- Design: [`docs/architecture/admin-hub-design.md`](docs/architecture/admin-hub-design.md)
- Backlog: [`docs/BACKLOG.md`](docs/BACKLOG.md)
- Related: `levix-platform` (client-side crates), `any-context` (first product).
